Resursprofil: SE EHDS DocumentReference – Anteckningar (GetCareDocumentation)

Officiell URL: https://fhir.inera.se/ig/ehds-tk/StructureDefinition/SEEHDSDocumentReference Version: 0.9.0
Draft per 2026-11-16 Beräkningsbart namn: SEEHDSDocumentReference

Profil för vårdanteckningar mappat från RIVTA-tjänstekontraktet GetCareDocumentation (clinicalprocess:healthcond:description v3.0). Täcker NPÖ 3.0 och 1177 Journal 3.0.

Använder JoL-header v2.2 (ej PatientSummaryHeader): accessControlHeader för PDL, record för journaluppgift-metadata, author för dokumentationsansvarig, signature för signeringsinformation.

Användningar:

  • CapabilityStatements som använder denna Profil: SE EHDS Resource Access Provider
  • Denna Profil används inte av några profiler i denna implementationsguide

Du kan också kontrollera användningar i FHIR IG-statistiken
