Extension: Godkänd för patient

Officiell URL: https://fhir.inera.se/ig/ehds-tk/StructureDefinition/approved-for-patient Version: 0.9.0
Draft per 2026-11-16 Beräkningsbart namn: ApprovedForPatient

Anger om information är godkänd för delning med patient (approvedForPatient, Regel 3).

Context of Use

    Denna extension kan användas på följande element

    • Element-ID: Element

Usage info

Användningar:

  • Använd denna Extension: SE EHDS CarePlan – Vårdplan (GetCarePlans)

Du kan också kontrollera användningar i FHIR IG-statistiken
