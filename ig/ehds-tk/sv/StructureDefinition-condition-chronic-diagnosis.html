Extension: Kronisk diagnos

Officiell URL: https://fhir.inera.se/ig/ehds-tk/StructureDefinition/condition-chronic-diagnosis Version: 0.9.0
Draft per 2026-11-16 Beräkningsbart namn: ConditionChronicDiagnosis

Anger om diagnosen är kronisk (true) eller inte kronisk (false) (diagnosisBody.chronicDiagnosis). Se DIAG-001.

Context of Use

    Denna extension kan användas på följande element

    • Element-ID: Condition

Usage info

Användningar:

  • Använd denna Extension: SE EHDS Condition – Diagnos (GetDiagnosis)

Du kan också kontrollera användningar i FHIR IG-statistiken
